Database Query Tuning Rules
Equality First Rule: Place equality predicates (`status = ACTIVE`) before range conditions in composite index.
Covering Index with INCLUDE: Stores projection columns in index leaf pages, eliminating table heap lookups.
Sort Order Alignment: Aligning index order (`created_at DESC`) removes expensive in-memory sort buffer spills.
