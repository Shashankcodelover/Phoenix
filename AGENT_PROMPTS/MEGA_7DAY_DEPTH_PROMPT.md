## 🛠️ THE 5-STEP PROTOCOL FOR EVERY SINGLE FEATURE

Whenever you pick up a feature, execute these 5 steps in strict sequence:

### STEP 1: Scan, Audit & Expose Loopholes
- Scan the existing implementation file(s) and related backend endpoints.
- List all UX flaws, missing edge cases, error vulnerabilities, and missing competitor advantages.
- Assign an initial Quality Grade (e.g. Grade C: 52/100).

### STEP 2: Competitor Benchmarking & Architectural Design
- Compare the feature directly against the market leader (e.g. Unstop for assessments, LeetCode for studios, ByteByteGo for system design).
- Define what Phoenix must do to visibly outperform them (e.g. instant state tracing instead of static output, real-time proctoring logs, sub-millisecond local execution).

### STEP 3: Deep Production Implementation
- Write clean, production-grade, modular code.
- Implement both the visual presentation (CSS/HTML with glassmorphism, responsive grids, and micro-interactions) and the client/server runtime logic.
- Include full error handling, defensive fallbacks, and zero external dependency fragility.

### STEP 4: Automated Playwright User-Flow Verification
- Create or update an automated Playwright test script (`test_<feature_name>.py`).
- Launch headless Chromium, navigate to the local endpoint (e.g. `http://localhost:5000/...`), and simulate exact user behaviors:
  - Button clicks, keystrokes, shortcuts (`Ctrl+Enter`).
  - Edge cases: window blur/tab switch, empty inputs, extreme scale test (10,000 items).
  - Assertions on DOM elements, latency measurements, and state transitions.
- Capture high-resolution screenshots and save them as verified artifacts.
- Enforce 100% pass rate. If any assertion fails, fix the code immediately and rerun until green.

### STEP 5: Diagnostic Report & Scorecard Update
- Output a structured summary:
  - Feature Name & Target File Links.
  - Competitor Overcome & Distinct Architectural Advantage.
  - Automated Verification Logs (All tests passed, execution latency in ms).
  - Updated Quality Grade (e.g. Grade A+: 98/100).
