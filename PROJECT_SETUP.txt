2. PREREQUISITES
-------------------------------------------------------------------------------
- Node.js (v18.0.0 or higher)
- MongoDB (v6.0+ local or Atlas cloud instance)
- Docker & Docker Compose (optional for containerized deployment)

Verify installation:
  node -v
  npm -v
  mongod --version

-------------------------------------------------------------------------------
3. LOCAL DEVELOPMENT SETUP
-------------------------------------------------------------------------------

Step 1: Install Backend Dependencies
  cd sup-backend
  npm install

Step 2: Environment Configuration
  Copy .env.example to .env inside sup-backend:
    cp .env.example .env

  Set your API keys:
    PORT=5000
    MONGO_URI=mongodb://127.0.0.1:27017/phoenix-prep
    JWT_SECRET=phoenix_super_secret_jwt_key_2026
    GEMINI_API_KEY=YOUR_GEMINI_KEY
    GROQ_API_KEY=YOUR_GROQ_KEY

  *Note: If API keys are left blank, Phoenix automatically uses local procedural AI fallbacks!*

Step 3: Start the Server
  npm start
  (or: node server.js)

Expected output:
  Server running on http://localhost:5000

Step 4: Launch Frontend
  Open `sup-frontend/splash/splash.html` in your browser or via VS Code Live Server.

-------------------------------------------------------------------------------
4. DOCKER DEPLOYMENT (RECOMMENDED FOR PRODUCTION)
-------------------------------------------------------------------------------

Launch the entire stack (MongoDB + Express Backend + Security Shield) in 1 click:

  docker-compose up -d --build

Verify running containers:
  docker-compose ps

Stop stack:
  docker-compose down
